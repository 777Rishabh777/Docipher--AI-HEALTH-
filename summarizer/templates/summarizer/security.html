Security Infrastructure

Enterprise-grade security built directly into Docipher's DNA.

Security is not an afterthought at Docipher. Because we handle sensitive medical and health data, we utilize the most stringent, cutting-edge technology to ensure your information remains strictly confidential and immutable.

Data Encryption

  • At Rest: All databases and object storage are encrypted using AES-256 standard.
  • In Transit: All communications between your device, our servers, and third-party APIs use TLS 1.3 with Perfect Forward Secrecy (PFS).
  • Key Management: We utilize hardware security modules (HSMs) and automated key rotation to prevent key compromise.

Cloud Infrastructure

  • Hosting: Deployed on SOC2 Type II and ISO 27001 certified cloud providers.
  • DDoS Protection: Enterprise-grade WAF and DDoS mitigation layers protect against volumetric and application-layer attacks.
  • Network Isolation: Databases and sensitive microservices are deployed within private Virtual Private Clouds (VPCs) with no direct internet ingress.

Identity & Access

  • Authentication: Secure password hashing using PBKDF2/Argon2. CSRF and XSS protections are enforced framework-wide.
  • Session Management: Secure, HttpOnly, and SameSite strict cookies are used for all authentication tokens.
  • Zero Trust: Internal access to infrastructure is strictly gated by Zero Trust network access policies and Multi-Factor Authentication (MFA).

Continuous Testing

  • Vulnerability Scans: Weekly automated scanning of infrastructure, dependencies, and containers for known CVEs.
  • Penetration Testing: Bi-annual manual penetration testing performed by accredited third-party security firms.
  • Code Review: Mandatory peer reviews and automated SAST/DAST tooling embedded in our CI/CD pipelines.

Vulnerability Disclosure Program

Security is a collaborative effort. We deeply appreciate the work of independent security researchers who help keep Docipher safe. If you believe you have discovered a security vulnerability in our platform, please report it immediately.

Report Vulnerability

We promise to investigate all legitimate reports promptly and will not pursue legal action against researchers acting in good faith under our disclosure guidelines.
